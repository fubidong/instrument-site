## 文档维护规则

1. 新增文档必须在本索引中登记。
2. 文档内容变更后，必须同步更新本索引的状态。
3. 已失效或被替代的文档，标注"已归档"并移至 `archive/` 目录，不得留在主目录误导。
4. 代码与文档冲突时，以代码和当前运行证据为准，同时更新文档。
