# 立项章程 — 多品牌仪器仪表企业站点

## 1. 项目背景

公司是多家仪器仪表厂商的代理商，需要一个专属的企业官网来：
- 展示代理的多个品牌和产品线
- 提供产品参数、图片、PDF 技术资料下载
- 收集潜在客户的询价/留言线索，进入后台跟进
- 支持中英文双语（面向国内和海外客户），后期扩展俄语

现有方案（WordPress）定制受限、不满意，需要从零搭建一个贴合仪器仪表代理行业的专属系统。

## 2. 项目目标

- **第一目标**：上线一个专业、可维护的多品牌仪器仪表企业官网，公网可访问，中英双语。
- **第二目标**：运营人员可通过后台独立维护品牌、产品、资料、新闻和询价线索，无需技术人员介入。
- **第三目标**：产品资料可批量导入，后期可通过采集工具高效扩充。

## 3. 用户角色

| 角色 | 说明 | 权限 |
|---|---|---|
| 公网访客 | 潜在客户、采购人员、工程师 | 浏览产品、下载资料、提交询价/留言 |
| 运营管理员 | 公司内部运营人员（单账号） | 后台登录，管理全部内容和线索 |

## 4. 功能清单

### 4.1 前台（公网展示）

| 模块 | 功能 | 优先级 |
|---|---|---|
| 首页 | 品牌轮播、热门产品、行业资讯、公司简介入口 | P0 |

| 产品类别 | 按类别浏览（示波器/信号发生器/电源/万用表/频谱仪/网络分析仪/探头等） | P0 |
| 产品系列 | 品牌下的产品系列列表 | P0 |
| 产品详情 | 型号、参数规格表、产品图片、PDF 资料下载、相关产品、询价按钮 | P0 |
| 资料下载中心 | 按品牌/类别/类型筛选 PDF 资料 | P1 |
| 新闻/技术文章 | 列表 + 详情，支持多语言 | P1 |
| 关于我们 | 公司介绍、联系方式 | P0 |
| 询价/留言 | 表单提交（姓名、公司、联系方式【必填】、邮箱【选填】、国家/地区、关联产品、需求描述） | P0 |
| 搜索 | 产品型号/名称搜索 | P1 |

|---|---|---|

## 5. 多语言策略

- **上线语言**：中文（zh，默认）、英文（en）
- **后期扩展**：俄语（ru），只需新增语言文件和翻译内容，不改代码结构
- **UI 文案**：通过 next-intl 语言文件管理（`messages/{locale}.json`）
- **产品内容**：通过数据库翻译表管理（每个产品/品牌/文章有对应语言的翻译记录）
- **PDF 资料**：按语言标注（中文资料/英文资料），产品详情页按当前语言优先展示对应资料
- **路由**：`/{locale}/...` 格式，默认中文

## 6. 产品资料结构（参考 siglent 官网）

参考鼎阳科技（siglent.com）的资料组织方式：

- **产品类别**：示波器、函数/任意波形发生器、射频/微波信号发生器、频谱分析仪、矢量网络分析仪、电源、电子负载、万用表、探头/附件等
- **资料类型**：数据手册（Datasheet）、用户手册、编程手册、快速指南、服务手册、应用说明
- **命名规律**：`{型号/系列} {资料类型}`，版本号前缀 `CN`=中文、`EN`=英文
- **产品照片**：store.siglent.com 风格的产品分类展示

批量导入时，可通过解析 PDF 文件名自动识别型号、资料类型、语言和版本。

## 7. 非目标（明确不做）

- 在线支付、购物车、订单交易（第一版是询价制，不做电商）
- 多租户 SaaS（公司自有，单站部署）
- 移动端 APP（响应式网站覆盖手机访问）
- ERP/CRM 深度集成（第一版不做，线索可导出 Excel）
- 用户注册/会员体系（公网访客无需登录）
- 在线客服系统（第一版用询价表单+联系方式）

## 8. 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 框架 | Next.js (App Router) + TypeScript | 全栈一体，SSR 对 SEO 友好 |
| UI | Tailwind CSS + shadcn/ui | 现代、可定制、AI 友好 |
| 多语言 | next-intl | 路由级多语言 |
| 数据库 | PostgreSQL | 关系型，适合产品数据 |
| ORM | Prisma | 类型安全，migration 管理 |
| 认证 | 自建轻量 session（单管理员） | 不引入重型 auth 库 |
| 部署 | 阿里云 ECS + 宝塔 + PM2 + Nginx | 本地测试后上线 |
| 包管理 | pnpm | 快速、节省磁盘 |

## 9. 验收标准

项目完成的判定标准：

1. **前台**：首页、品牌页、产品列表/详情、询价表单、关于我们页面均可正常访问，中英双语切换无硬编码残留。
2. **后台**：管理员可登录，可完整执行品牌→类别→系列→型号→资料的增删改查，可管理询价线索状态。
3. **数据**：至少导入 1 个品牌、3 个类别、5 个系列、10 个产品型号的真实数据，产品详情页参数表和 PDF 下载正常。
4. **询价**：前台提交询价后，后台可见新线索，状态可流转。
5. **多语言**：中英文页面内容完整，切换语言后 URL、文案、产品内容均正确变化。
6. **部署**：本地测试通过后，成功部署到阿里云，HTTPS 可访问，宝塔面板可管理。
7. **性能**：首页加载 LCP < 2.5s（本地网络），产品详情页可正常打开。
8. **安全**：询价接口有基本防刷（速率限制），后台路由未登录不可访问，无 SQL 注入/XSS 明显漏洞。

## 10. 风险与约束

| 风险 | 影响 | 应对 |
|---|---|---|
| 产品资料版权 | 使用厂商官方资料需确认授权 | 作为代理商使用厂商官方推广资料通常被允许；采集时仅采集公开资料，不爬取受限内容 |
| 多语言内容维护量 | 每个产品都要中英双语 | 第一版可先中文全量+英文核心产品，逐步补齐；后台支持标记翻译状态 |
| PDF 文件存储 | 大量 PDF 占用空间 | 本地存储起步，后期可迁移阿里云 OSS |
| 采集工具合规性 | 采集厂商官网可能被反爬 | 后期做采集时遵守 robots.txt，控制频率，优先用厂商提供的资料包 |
| 单人维护 | 运营人员不熟悉技术 | 后台操作尽量简单直观，提供操作手册 |
