## 0. 当前设计系统快照（Design System Snapshot）

### 配色 token（`src/app/globals.css` `:root` L51–84）
- **全部为纯灰 OKLCH，chroma 恒为 0**：`--background: oklch(1 0 0)`、`--foreground: oklch(0.145 0 0)`、`--primary: oklch(0.205 0 0)`、`--muted: oklch(0.97 0 0)`、`--border: oklch(0.922 0 0)`、`--ring: oklch(0.708 0 0)`……无任何色相。
- **唯一有色 token**：`--destructive: oklch(0.577 0.245 27)`（红），仅用于破坏性操作。
- **无品牌强调色 token**。`--accent` 被 shadcn 占用为浅灰 `oklch(0.97 0 0)`，并不是“品牌强调色”。
- **radius = `0.625rem`**（10px），`@theme inline` 派生 sm/md/lg/xl/2xl/3xl/4xl（L42–48）。
- **关键事实：这套 token 实际没人用**。前台所有可见颜色都直接写 Tailwind 工具类——`bg-sky-600` / `text-sky-600` / `text-slate-800` / `bg-slate-50` / `border-slate-200`。真正的“事实 accent”是 `sky-500/600`，真正的“事实中性色”是 `slate-*`。token 块是死的，UI 是散装的。

### 字体
- `src/app/layout.tsx` 用 `next/font/google` 加载 **Geist Sans**（变量 `--font-geist-sans`）+ **Geist Mono**（`--font-geist-mono`）。
- **接线有 bug**：`globals.css` `@theme inline` 写的是 `--font-sans: var(--font-sans)`（L10），引用了一个**从未定义**的 `--font-sans`；root layout 定义的是 `--font-geist-sans`。结果 `@apply font-sans`（L128）解析到空变量，正文回退到浏览器默认 sans，**Geist 根本没被应用上**。`--font-mono: var(--font-geist-mono)`（L11）这一条是对的。
- 实际是**单字体**（sans），Geist Mono 只在产品型号 `font-mono`（首页 L214）露面。无 display/body 配对。
- globals.css 后半段（L596+）混入大量从品牌站抄来的 `font-family`：`Noto Sans SC`、`YouSheBiaoTiHei`、`Microsoft YaHei`、`PingFang SC`、`Source Han Sans CN` 等，全部挂在 `.rich-text` 下，属于品牌定制内容，不是系统字体。

### 导航 / Footer 结构
- **顶栏**（layout L55–108）：最上一条深灰 utility bar（站名 + 热线 + 语言切换 + 在线询价）；其下 sticky `top-0 z-50` 主导航 = 左 logo 方块（sky-600）+ 站名/英文名，中间 `SiteNav` 菜单 + Catalog 链接，右侧搜索 + 品牌站切换。白底、1px `border-slate-200`、`backdrop-blur`。
- **移动端**：导航整段 `hidden md:flex`，**<md 没有任何汉堡/抽屉，等于全站无导航**。
- **Footer**（layout L113–183）：`slate-50` 底，3 列 grid（关于+联系方式 / 产品中心 / 代理品牌），顶部 hairline，底部居中版权行。
- **下拉菜单**（site-nav.tsx）：多级树，**只在 `group-hover` 展开**（L57），无 focus/tap 支持。

### 判定的当前 genre
表面定位是 modern-minimal（B2B 仪器代理），实际产出是 **shadcn 开箱默认 + Tailwind UI 样板**：纯灰 token、散装 sky 强调、居中 hero、3 列产品卡、3 项 stat、AI nav、3 列 footer。这是 Hallmark 所说的 **default-attractor sameness / SaaS hero + 3-feature row** 结构指纹，而非真正的现代极简。

## 1. Ranked Punch List（按严重度排序）

### CRITICAL

**[C1 · gate 48 设计令牌失活 / token 纪律] — globals.css:51–84 与全站**
`--primary/--accent/--ring` 等 shadcn token 全是 chroma=0 的纯灰，且没有任何组件消费它们；前台真实颜色全是散装工具类（`sky-*`/`slate-*`）。“设计系统”不驱动 UI，真正 accent 是随手写的 sky-500。
→ 把品牌蓝落成一个命名 token（如 `--color-brand: oklch(... 0.13 245)`），让 `--primary`/`--ring`/hover 态都指向它；系统性替换 `sky-600/sky-500` 为 `bg-primary`/`text-primary`，`slate-*` 收敛到 token 中性色阶。

**[C2 · 项目宪法硬违规（多语言硬编码）] — layout.tsx:59,64,70,118–146 及全部页面**
全站用 `isEn ? "中文" : "English"` 三元硬编码用户可见文案（layout、首页、品牌列表/详情、产品详情、contact 皆是），未走 `messages/{zh,en}.json`。违反宪法“禁止硬编码中/英字符串”。
→ 把所有前台文案抽进 messages，组件改用 `useTranslations`/`t()`；这是架构级整改，不止视觉问题。

**[C3 · gate 1 字体接线断裂 / 单字体] — globals.css:10 + layout.tsx:6–14**
`@theme inline` 的 `--font-sans: var(--font-sans)` 引用了未定义变量，Geist Sans 实际未生效，正文回退系统默认；且全站单 sans、无 display 配对。
→ 改为 `--font-sans: var(--font-geist-sans)`；并为标题引入第二个 display 面（见 S 节 redesign 建议）。

**[C4 · gate 42 AI 导航指纹 + 移动端无导航] — layout.tsx:77–108 / site-nav.tsx:21**
导航是“左 wordmark + 中链接 + 右按钮/搜索”的标准 N1b SaaS 指纹；且 `<md` 整段 `hidden md:flex`，小屏完全没有菜单。
→ 补移动端抽屉/汉堡（这是硬伤）；桌面端可保留三栏但加差异化（如把搜索/品牌切换收进非对称位置）。

**[C5 · gate 46 虚构指标] — page.tsx:271–272**
关于我们 stat 行硬编码 `"1000+"` 款产品、`"7×24"` 技术支持，无来源；只有 `brands.length` 是真数据。
→ 用真实产品数（已有 `db.product.count`）替换 `1000+`，`7×24` 若无承诺则删掉或换成真实服务项。

**[C6 · gate 2 渐变 hero] — page.tsx:117**
`bg-gradient-to-br from-slate-900 via-slate-800 to-sky-900` 渐变 hero 背景。虽非紫粉渐变，但仍是“渐变铺底 hero”这一 AI 惯技。
→ 用单一深色实底（带极轻微同色相 tint），或至多一个同色相 two-stop 极弱渐变；不要 slate→sky 跨色相。

**[C7 · hover-only 下拉 / 触屏不可达] — site-nav.tsx:57**
多级菜单仅 `group-hover:visible/opacity` 展开，无 `:focus-within`、无键盘、无 tap 目标。触屏用户和键盘用户进不了二级菜单。
→ 加 `focus-within` 展开 + 可点击的 trigger（button/aria-expanded），或改用受控 hover 菜单；触屏点击一级项即展开。

**[C8 · 违反宪法（next/image 禁用）] — page.tsx:204 / brands/page.tsx:53 / brands/[code]/page.tsx:307**
用原生 `<img>` + `eslint-disable-next-line @next/next/no-img-element`，而非 `next/image`。
→ 迁移到 `next/image`（产品图/品牌 logo 统一），并补 `sizes`/`fetchpriority`。

### MAJOR

**[M1 · gate 6 居中到底的 hero] — page.tsx:117–140**
h1、lede、双 CTA 全部居中同一竖轴，py-20，无错位/无图文。经典 SaaS hero。
→ 左对齐（或非对称栅格），让 lede 或 CTA 偏轴；至少打破两处居中。

**[M2 · gate 3 三等分产品卡 / icon-tile 模板] — page.tsx:177–236, 247–258 / brands/page.tsx:39–66**
推荐产品 `grid lg:grid-cols-3` 等宽卡片、等距 padding、统一 hover；类别墙也是 `gap-px` 等分格。
→ 变体卡高/宽度，或改成非对称列表 + 大图主卡；不必每张都 `rounded-lg border p-5`。

**[M3 · gate 43 AI footer 指纹] — layout.tsx:113–183**
3 列链接 + 居中版权 + hairline + 灰底，是 Ft3 索引列模板。B2B 代理站确实需要链接列，但缺“收口”性格。
→ 保留产品/品牌列但加一句 colophon 式站点定位（或品牌背书行），版权行左对齐而非居中。

**[M4 · 双 `<h1>`] — brands/[code]/page.tsx:310 与 :370**
品牌名一个 h1，右侧分类名又是一个 h1。一页两个 h1，SEO/大纲受损。
→ 把 L370 降为 `h2`，品牌名保持唯一 h1。

**[M5 · 散装 hover 微交互 / transition 滥用] — page.tsx:152,200,252 / 全站**
卡片统一 `hover:border-sky-300 hover:shadow-md`、`transition`，无指定属性、无缓动、无 reduced-motion 兜底。
→ 每个元素只留一种 hover 信号（颜色或下划线），明确 `transition: color/border-color ...`，加 `prefers-reduced-motion`。

**[M6 · gate 22 零色度中性色（genre 宽限但仍偏平）] — globals.css:52–83**
所有中性色 `oklch(... 0 0)` 纯灰。modern-minimal 允许 monochrome，但这里叠加散装 sky 后整体偏“默认 shadcn”。
→ 不必强加温色；但应把中性色统一进 token 阶并围绕品牌蓝微 tint（≥0.005 色度），消除“扁平塑料感”。

**[M7 · globals.css 近 9000 行品牌抄站 CSS 泄漏] — globals.css:132–9500**
`.rich-text` 下混入大量从品牌站复制的硬编码样式（`#38bdf8`、`#0284c7`、`YouSheBiaoTiHei`、`Microsoft YaHei`、`#666` 等），非 token、跨品牌污染。
→ 把品牌定制样式下沉到各品牌内容片段/独立层，公共 globals 只留系统 token 与公共类。

**[M8 · footer 品牌链接绕过 i18n] — layout.tsx:172**
`<SiteLink href={/${b.code.toLowerCase()}}>` 用裸 `next/link`，未走 `@/i18n/navigation`，丢 locale 前缀。
→ 改用 i18n 感知的 `Link`（或 `brandPath` 工具）。

### MINOR

**[m1 · 任意值尺寸] — layout.tsx:87 `text-[10px]`**
非刻度字号。→ 用 token 字号或最小 `text-[11px]` 以上。

**[m2 · 联系页占位文案] — contact/page.tsx:54,60,66**
电话/邮箱/地址缺失时统一“Coming soon / 敬请期待”。→ 真实字段为空时整行不渲染。

**[m3 · 面包屑/链接两侧箭头符号手写] — brands/[code]:320, 首页:174 等**
`→` `↗` 手写符号可用，注意多语言下对齐；非阻断。

**[m4 · gate 51 长词断行] — 品牌/型号名（page.tsx:214, brands/[code]:310）**
大写型号 `font-mono` 无 `overflow-wrap:anywhere; min-width:0`，窄屏可能溢出。
→ 对 display/型号容器加 `min-w-0` + `overflow-wrap:anywhere`。

**[m5 · gate 36 垂直基线未显式居中] — site-nav.tsx:21, layout.tsx:78**
flex 行混高元素（button + 文字）建议显式 `items-center`（多数已写，但 dropdown trigger 可复查）。

**[m6 · 顶栏 utility bar 文案也硬编码] — layout.tsx:59,64,70**
同 C2，一并纳入 messages 抽取。

## 2. 汇总

- **critical: 8 · major: 8 · minor: 6**
- 结论：**reads as AI-generated（且部分破坏项目宪法）**。视觉表面不算灾难（克制、不花哨），但结构指纹是默认 SaaS 模板：居中 hero → 品牌墙 → 3 列产品卡 → 类别格 → 居中关于 + 3 假 stat → AI nav → 3 列 footer。真正的品牌系统还没建立——token 是死的、颜色是散装的、字体没接上、移动端没导航。
- 最该先动的三件：**(C2/C8) 宪法合规（抽 messages + next/image）**、**(C3) 把 Geist 接上并配对 display 字体**、**(C1) 把散装 sky 收敛成一个品牌 token**。
